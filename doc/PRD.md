# PRD: EBS-AI HUB

## 1. 목적

EBS-AI HUB는 조직 내부 사용자가 여러 업무 도구를 하나의 웹 허브에서 접근하고 관리할 수 있도록 하는 통합 업무 포털입니다. 사용자는 인증 후 대시보드에서 필요한 앱을 실행하고, 마켓플레이스에서 앱을 설치하거나 활성화할 수 있습니다.

## 2. 배경

업무 도구가 분산되어 있으면 사용자별 접근 경로, 설치 상태, 권한 관리, 데이터 확인 흐름이 복잡해집니다. EBS-AI HUB는 앱 레지스트리 기반 구조를 통해 업무 모듈을 일관된 방식으로 배포하고, 사용자별 활성 앱 구성을 로컬 상태에 저장해 개인화된 업무 화면을 제공합니다.

## 3. 목표

- 로그인 기반의 안전한 업무 허브 제공
- 대시보드에서 사용자가 활성화한 앱 패널 표시
- 마켓플레이스에서 앱 설치 및 제거 흐름 제공
- 관리자 전용 사용자 관리 및 환경 설정 기능 제공
- 자산 실사 앱을 통해 QR 스캔, 사진 저장, 실사 결과 관리, Excel 내보내기 지원
- HTTPS 개발 서버를 통해 카메라, PWA 등 보안 컨텍스트가 필요한 기능 지원

## 4. 사용자

- 일반 사용자: 대시보드, 설치 앱, 마켓플레이스, 설정 기능을 사용합니다.
- 관리자: 일반 사용자 기능에 더해 사용자 관리, 환경 설정, 모듈 배포 관련 기능에 접근합니다.

## 5. 주요 기능

### 인증 및 권한

- 로그인, 비밀번호 재설정 화면 제공
- 인증된 사용자만 주요 화면 접근 가능
- 관리자 권한이 필요한 화면은 별도 보호 라우트로 제한

### 대시보드

- 활성화된 앱을 패널 형태로 표시
- 사용자별 활성 앱 목록을 로컬 저장소에 보존

### 앱 관리

- 중앙 앱 레지스트리에서 설치 가능 앱 관리
- 기본 설치 앱과 기본 활성 앱 구분
- 코어 앱은 제거되지 않도록 보호
- 마켓플레이스와 설치 앱 화면에서 앱 설치 상태 관리

### 자산 실사

- 자산 데이터 조회 및 자산 번호 정규화
- QR 스캐너를 통한 자산 식별
- 실사 세션 생성, 조회, 삭제, 완료 처리
- 자산 상태, 위치, 부서, 비고, 확인자 기록
- 사진 저장 및 삭제
- 실사 결과 Excel 다운로드
- 원격 동기화 및 AI 검증 기능 확장 지점 제공

## 6. 화면 범위

- `/login`: 로그인
- `/reset-password`: 비밀번호 재설정
- `/dashboard`: 대시보드
- `/installed-apps`: 설치된 앱
- `/marketplace`: 앱 마켓플레이스
- `/users`: 사용자 관리, 관리자 전용
- `/modules`: 모듈 화면
- `/settings`: 설정

## 7. 기술 요구사항

- React + TypeScript 기반 프런트엔드
- Vite 개발 서버 사용
- React Router 기반 라우팅
- Supabase 연동 가능 구조
- IndexedDB 또는 로컬 저장소 기반 클라이언트 데이터 저장
- HTTPS 로컬 개발 서버 제공

## 8. 비기능 요구사항

- 인증되지 않은 사용자는 보호 화면에 접근할 수 없어야 합니다.
- 관리자 전용 기능은 관리자 권한이 없는 사용자에게 제한되어야 합니다.
- 앱 추가 시 중앙 레지스트리 등록만으로 대시보드와 마켓플레이스에 반영되는 구조를 유지해야 합니다.
- 자산 실사 기능은 네트워크가 불안정한 환경에서도 로컬 저장 기반으로 사용할 수 있어야 합니다.
- 카메라 및 QR 스캔 기능은 브라우저 보안 정책을 만족하는 HTTPS 환경에서 동작해야 합니다.

## 9. 성공 기준

- 사용자가 로그인 후 대시보드에 접근할 수 있습니다.
- 설치된 앱과 활성 앱 상태가 사용자 브라우저에 유지됩니다.
- 관리자는 사용자 관리 화면에 접근할 수 있고, 일반 사용자는 접근할 수 없습니다.
- 자산 실사 세션을 만들고 결과를 저장한 뒤 Excel 파일로 내보낼 수 있습니다.
- 로컬 개발 서버가 `https://localhost:5173/`에서 실행됩니다.

## 10. 제외 범위

- 정식 운영 인프라 배포 자동화
- 서버 측 API 상세 명세
- 외부 시스템별 데이터 연동 상세 정책
- 모바일 네이티브 앱 구현
