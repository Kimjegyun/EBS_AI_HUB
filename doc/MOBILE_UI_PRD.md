# PRD: EBS-AI HUB Mobile UI

## 1. 목적

EBS-AI HUB Mobile UI는 기존 데스크톱 중심의 AI 업무 포털을 스마트폰에서도 안정적으로 사용할 수 있도록 별도 모바일 화면 체계를 정의하는 문서입니다. 사용자는 핸드폰에서 로그인 후 대시보드, AI 앱, 캘린더, 할 일, 재물조사, 설정 확인 등 핵심 기능에 접근할 수 있어야 하며, ADMIN은 모바일에서도 최소한의 승인·사용량 확인·긴급 관리 업무를 수행할 수 있어야 합니다.

모바일 UI는 기존 EBS-AI HUB의 구조와 권한 체계를 유지하되, 작은 화면에서 드래그 기반 위젯 조작을 그대로 강제하지 않고 탭, 목록, 카드, 하단 내비게이션 중심의 조작 방식으로 재구성합니다.

## 2. 배경

현재 EBS-AI HUB는 데스크톱 대시보드와 위젯 기반 업무 화면에 최적화되어 있습니다. 그러나 실제 업무 환경에서는 회의실, 이동 중, 장비실, 현장 점검, 재물조사 등 PC 접근이 어려운 상황에서도 AI 도구와 업무 앱을 빠르게 사용해야 합니다.

특히 재물조사 앱은 QR 스캔, 사진 촬영, 현장 메모 입력 등 모바일 사용성이 필수이며, 캘린더·할 일·AI 질의 기능도 스마트폰에서 즉시 확인하고 처리할 수 있어야 합니다. 따라서 기존 기능을 유지하면서 모바일 전용 레이아웃과 조작 방식을 별도로 설계해야 합니다.

## 3. 목표

- 스마트폰 브라우저에서 EBS-AI HUB 핵심 기능 사용 가능
- USER와 ADMIN 권한 구조를 모바일에서도 동일하게 적용
- 모바일 전용 하단 내비게이션과 단일 컬럼 화면 제공
- 대시보드 위젯을 모바일에서는 카드 목록 또는 탭 형태로 표시
- 재물조사 앱의 QR 스캔, 사진 촬영, 현장 입력 사용성 강화
- AI 앱에서 모바일 입력, 대화 확인, 사용량 안내를 명확히 제공
- 새로고침 후에도 사용자별 모바일 UI 상태 유지
- 데스크톱 UI와 데이터 구조는 공유하되 모바일 레이아웃 상태는 별도 저장

## 4. 사용자

- 일반 USER: 핸드폰에서 AI 질의, 캘린더 확인, 할 일 관리, 재물조사, 메모, 앱 실행 기능을 사용합니다.
- ADMIN: 핸드폰에서 사용자 승인 현황, API 사용량, USER별 한도, 서비스 상태를 간단히 확인하고 필요한 관리 작업을 수행합니다.
- 현장 사용자: 장비실, 스튜디오, 사무실 외부 공간에서 QR 스캔, 사진 촬영, 자산 상태 기록을 수행합니다.

## 5. 주요 기능

### 인증 및 권한

- 모바일 로그인 화면은 한 손 조작이 가능한 단일 컬럼 구조로 제공합니다.
- USER 모드에서는 API 키 설정 화면을 노출하지 않습니다.
- ADMIN 모드에서는 API 키, 사용자 승인, 사용량 한도 관리에 접근할 수 있습니다.
- 세션과 사용자별 로컬 데이터는 기존 사용자 스코프 저장 정책을 유지합니다.

### 모바일 대시보드

- 데스크톱의 자유 배치형 위젯 그리드는 모바일에서 사용하지 않습니다.
- 모바일 대시보드는 활성 앱을 세로 카드 목록으로 표시합니다.
- 각 앱 카드는 접기/펼치기 또는 전체 화면 진입을 지원합니다.
- 사용자가 마지막으로 열어둔 앱, 카드 순서, 접힘 상태는 모바일 전용 저장 키로 유지합니다.
- 위젯 이동은 드래그가 아니라 “순서 변경” 메뉴 또는 편집 모드에서 처리합니다.

### 모바일 내비게이션

- 화면 하단에 고정 내비게이션을 제공합니다.
- 기본 탭은 `홈`, `AI`, `일정`, `앱`, `내정보`로 구성합니다.
- ADMIN은 `관리` 탭이 추가되거나 `내정보` 안에 관리자 메뉴를 표시합니다.
- 상단에는 현재 화면 제목과 최소 액션 버튼만 표시합니다.

### AI 앱

- 모바일에서는 대화 입력창을 화면 하단 고정 영역에 배치합니다.
- 긴 대화는 말풍선 목록으로 표시하고, 모델 선택은 상단 메뉴 또는 바텀시트로 제공합니다.
- USER는 API 키를 입력할 수 없고, ADMIN이 설정한 조직 API 키를 사용합니다.
- USER별 월간 사용량과 남은 횟수를 대화 입력창 근처에 표시합니다.
- 한도 초과 시 입력창을 비활성화하고 관리자에게 요청하는 안내를 표시합니다.

### 캘린더

- 모바일 캘린더는 월간 전체 그리드와 일정 목록을 분리합니다.
- 기본 화면은 이번 주/오늘 일정 중심으로 보여주고, 월간 보기는 별도 탭으로 제공합니다.
- 날짜 선택 시 하단 바텀시트로 해당 날짜의 일정, 할 일, 회사 휴일을 표시합니다.
- 새로고침 시 캘린더 전체가 로딩 화면으로 바뀌지 않고 기존 캐시 화면을 유지합니다.

### 할 일

- 오늘, 예정, 완료 탭을 제공합니다.
- 모바일에서는 빠른 추가 입력창을 상단 또는 하단에 배치합니다.
- 우선순위, 마감일, 완료 상태 변경은 스와이프 또는 체크박스로 처리합니다.

### 재물조사

- 모바일 최우선 앱으로 설계합니다.
- QR 스캔 버튼은 첫 화면에서 크게 표시합니다.
- 카메라 권한 안내, HTTPS 필요 안내, 스캔 실패 시 수동 입력 경로를 제공합니다.
- 자산 상세 화면은 자산명, 자산번호, 위치, 부서, 상태, 사진, 메모 순서로 구성합니다.
- 사진 촬영/첨부, 현장 메모, 상태 선택은 엄지 조작이 가능한 컨트롤로 제공합니다.
- 오프라인 또는 네트워크 불안정 상황에서도 임시 저장 후 동기화할 수 있어야 합니다.

### 앱 관리

- 모바일 앱 목록은 설치됨, 추천, 전체 앱 탭으로 구성합니다.
- 앱 활성화는 토글로 처리합니다.
- 데스크톱처럼 드래그 배치하지 않고, 모바일 홈에 표시할 앱 순서를 별도 관리합니다.

### ADMIN 관리

- 모바일 ADMIN 화면은 상세 관리보다 빠른 확인과 승인에 집중합니다.
- 사용자 승인 대기 목록, USER별 API 사용량, 한도 초과 사용자, 시스템 상태를 카드로 표시합니다.
- USER별 API 한도 수정은 숫자 입력과 저장 버튼으로 제공합니다.
- API 키 입력은 ADMIN 전용 설정 화면에서만 가능합니다.

## 6. 화면 범위

- `/login`: 모바일 로그인
- `/dashboard`: 모바일 홈 대시보드
- `/ai`: 모바일 AI 대화 화면
- `/calendar`: 모바일 일정 화면
- `/tasks`: 모바일 할 일 화면
- `/inventory`: 모바일 재물조사 화면
- `/installed-apps`: 모바일 앱 관리
- `/marketplace`: 모바일 앱 탐색
- `/users`: 모바일 사용자 관리, ADMIN 전용
- `/settings`: 모바일 설정, ADMIN 전용 API 설정 포함
- `/profile`: 내 정보, 사용량, 세션 관리

## 7. 기술 요구사항

- React + TypeScript 기반 기존 코드 구조 유지
- 동일한 인증, 권한, Supabase 연동 구조 사용
- 모바일 breakpoint 기준: `max-width: 767px`
- 모바일 전용 레이아웃 상태 저장 키 분리
- PWA 설치 가능 구조 유지
- 카메라/QR 기능을 위해 HTTPS 환경 필수
- IndexedDB 기반 현장 데이터 임시 저장 지원
- 하단 내비게이션, 바텀시트, 고정 입력창 등 모바일 컴포넌트 추가
- 모바일 터치 이벤트와 데스크톱 드래그 이벤트 충돌 방지

## 8. 비기능 요구사항

- 주요 버튼의 터치 영역은 최소 44px 이상이어야 합니다.
- 한 손 조작을 고려해 주요 액션은 화면 하단 또는 오른쪽 하단에 배치합니다.
- 텍스트는 작은 화면에서 줄바꿈되어도 버튼과 카드 영역을 침범하지 않아야 합니다.
- 새로고침 시 마지막 모바일 화면 상태가 유지되어야 합니다.
- 네트워크가 느려도 기존 캐시 데이터를 먼저 표시해야 합니다.
- USER는 API 키를 볼 수 없어야 하며, 로컬 저장소에 남아 있는 과거 키도 USER 모드에서 사용하지 않아야 합니다.
- 재물조사, 사진, QR 스캔 기능은 브라우저 권한 실패 상황에 대한 안내를 제공해야 합니다.
- 모바일 화면은 데스크톱 위젯 배치 기능을 그대로 축소하지 않고, 모바일 조작 방식에 맞게 별도 UX를 사용해야 합니다.

## 9. 성공 기준

- 스마트폰 브라우저에서 로그인 후 주요 앱에 접근할 수 있습니다.
- USER는 모바일에서 API 키 설정 화면을 볼 수 없습니다.
- ADMIN은 모바일에서 API 키 설정과 USER별 사용량 한도 관리에 접근할 수 있습니다.
- 모바일 대시보드는 새로고침 후에도 마지막 카드 순서와 상태를 유지합니다.
- 캘린더는 새로고침 시 전체 화면 깜빡임 없이 기존 화면을 유지합니다.
- 재물조사 앱은 모바일에서 QR 스캔, 사진 촬영, 상태 기록을 완료할 수 있습니다.
- AI 앱은 모바일에서 USER별 사용량 한도를 적용하고 한도 초과 시 호출을 차단합니다.
- 데스크톱 레이아웃과 모바일 레이아웃이 서로의 저장 상태를 덮어쓰지 않습니다.

## 10. 제외 범위

- 네이티브 iOS/Android 앱 개발
- 앱스토어 또는 플레이스토어 배포
- 푸시 알림의 네이티브 구현
- 모바일 전용 서버 API 신규 설계 전체
- 오프라인 동기화 충돌 해결의 고급 정책
- 음성 입력, 음성 출력, 생체 인증
- 모바일 전용 디자인 시스템 전체 재작성
