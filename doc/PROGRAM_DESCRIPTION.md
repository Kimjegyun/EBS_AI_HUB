# 프로그램 설명: EBS-AI HUB

## 개요

EBS-AI HUB는 조직 내부 업무용 앱을 한 곳에서 실행하고 관리하기 위한 웹 기반 앱 허브입니다. 사용자는 로그인 후 대시보드에서 필요한 업무 앱을 실행하고, 마켓플레이스에서 앱을 설치하거나 활성화할 수 있습니다.

## 기술 스택

- 프런트엔드: React, TypeScript
- 빌드 도구: Vite
- 라우팅: React Router
- 스타일링: Tailwind CSS 기반 구성
- 인증 및 외부 연동: Supabase 연동 구조 포함
- 데이터 처리: 로컬 저장소, IndexedDB, Excel 내보내기
- QR 스캔: `html5-qrcode`

## 주요 화면

- 로그인: 사용자 인증을 처리합니다.
- 대시보드: 활성화된 업무 앱을 모아 보여줍니다.
- 설치된 앱: 현재 설치된 앱 목록을 관리합니다.
- 마켓플레이스: 설치 가능한 앱을 탐색하고 설치합니다.
- 사용자 관리: 관리자만 접근 가능한 사용자 관리 화면입니다.
- 설정: 사용자 및 환경 관련 설정을 제공합니다.

## 내장 앱

- Calendar: 일정 관리 앱
- Codex: Codex 관련 작업 앱
- Inventory: 자산 실사 앱
- Quick Actions: 빠른 작업 실행 앱
- Tasks: 할 일 관리 앱
- Messages: 메시지 앱
- Notes: 노트 앱
- Bookmarks: 북마크 앱

## 자산 실사 앱 설명

자산 실사 앱은 조직 내 자산의 실제 상태를 확인하고 기록하기 위한 기능입니다. 사용자는 실사 세션을 만들고, QR 코드를 스캔하거나 자산 번호를 입력해 자산을 조회한 뒤 상태, 위치, 부서, 비고, 확인자, 사진 정보를 저장할 수 있습니다.

지원 기능:

- 실사 세션 생성 및 관리
- 자산 번호 조회 및 정규화
- QR 코드 스캔
- 실사 결과 저장
- 사진 첨부
- Excel 다운로드
- 동기화 기능 확장
- AI 검증 기능 확장

## 앱 확장 방식

앱은 `src/apps/registry.ts`의 중앙 앱 레지스트리를 통해 관리됩니다. 새 앱을 추가할 때는 앱 플러그인 파일을 만들고 레지스트리에 등록하면 대시보드, 마켓플레이스, 설치 앱 화면에서 같은 기준으로 사용할 수 있습니다.

## 실행 주소

로컬 개발 서버 기본 주소:

```text
https://localhost:5173/
```

HTTPS는 카메라, QR 스캔, PWA 등 브라우저 보안 컨텍스트가 필요한 기능을 지원하기 위해 사용됩니다.
