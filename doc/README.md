# EBS-AI HUB 문서

이 폴더는 EBS-AI HUB 웹 애플리케이션의 제품 요구사항, 프로그램 설명, 실행 방법, 변경 이력을 관리합니다.

## 문서 목록

- [PRD.md](./PRD.md): 제품 요구사항 문서
- [PROGRAM_DESCRIPTION.md](./PROGRAM_DESCRIPTION.md): 프로그램 개요 및 주요 기능 설명
- [SETUP.md](./SETUP.md): 로컬 개발 환경 실행 방법
- [CHANGELOG.md](./CHANGELOG.md): 변경 이력 기록
- [apps/](./apps/README.md): **앱별 실행 과정·메뉴얼·실행 순서 문서** — 모든 앱은 여기에 문서를 하나씩 두고, 기능을 바꿀 때 함께 갱신합니다. 신규 앱도 같은 규칙을 따릅니다.

## 프로젝트 개요

EBS-AI HUB는 React, TypeScript, Vite 기반의 웹 애플리케이션입니다. 로그인 기반의 허브 화면에서 대시보드, 설치된 앱, 마켓플레이스, 사용자 관리, 설정 화면을 제공하고, 앱 레지스트리를 통해 캘린더, Codex, 자산 실사, 빠른 작업, 할 일, 메시지, 노트, 북마크 앱을 관리합니다.
