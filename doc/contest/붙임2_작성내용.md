## 작성 방침

**유형 1에 체크**하되, 특정 모델을 탑재·배포하지 않고 **사용자가 모델을 선택**해
연결한다는 점을 ※ 줄에 함께 적습니다.

이 출품작의 AI 계층은 **모델을 고정하지 않는 선택 계층**입니다.
「나의 LLM」 앱에서 사용자가 쓰고 싶은 모델을 고르고, 자신의 키와 엔드포인트를
지정해 연결합니다. 온프레미스(오픈웨이트 모델 자체 구동)는 **사내 보안 데이터를
다루는 앱을 개발할 때** 쓰기 위해 갖춰 둔 경로입니다.

서식상 **유형 1을 체크하면 2번(기반 모델 정보)은 필수 작성**입니다. 그래서 2번에는
온프레미스 구동 경로의 **기준 모델(Qwen2.5-7B-Instruct, Apache-2.0)** 을 적고,
모델을 고정하지 않는다는 사실을 함께 명시합니다.

> ⚠️ **제출 전에 한 번만 해주세요.** 2번에 모델명을 적는 이상, 그 모델을 실제로 한 번
> 구동해 보는 것이 좋습니다. 현재 로컬 런타임이 설치돼 있지 않습니다.
> `ollama pull qwen2.5:7b` 후 설정에서 `ai_openai_base_url` 을 `http://localhost:11434/v1`,
> `ai_openai_model` 을 `qwen2.5:7b` 로 바꾸고 AI 교차검증을 한 번 실행하면 끝입니다.
> 끝나면 알려주세요 — 실제로 로컬 모델이 응답하는지 확인해 드리겠습니다.

## 관문 2에 걸리지 않는 근거 (심사 문의 대비)

부록2 Ⅱ장 관문 2가 제한하는 것은 *"외부 API 호출을 통해서만 작동하는 상용 API 전용
모델을 서비스 형태로 단순 연결한"* 출품작, 즉 **API를 빼면 아무것도 동작하지 않는 경우**입니다.
이 출품작은 두 가지 이유로 해당하지 않으며, 둘 다 저장소에서 확인 가능합니다.

**첫째, 핵심 기능이 AI를 쓰지 않습니다.**

| 기능 | AI 필요 |
|---|---|
| QR 스캔 → 자산 조회 (하이픈 무시 매칭) | ❌ |
| 운영관리부 양식 + ERP 엑셀 병합 | ❌ |
| 검수 기록 · 오프라인 동기화 | ❌ |
| 검수 4열 반영 ERP 엑셀 생성 | ❌ |
| 설치부서 대조(노랑/주황) 엑셀 생성 | ❌ |
| 본부 → 부서 → 확인자 커버리지 통계 | ❌ |
| 앱 마켓플레이스 · 원격 앱 배포 · 앱 이식 | ❌ |
| 장부·현물 대조 AI 교차검증 *(선택)* | ⭕ |

AI 키를 한 줄도 넣지 않아도 전 과정이 동작합니다.

**둘째, 오픈웨이트 모델 온프레미스 구동 경로를 제공합니다.**

이 경로는 형식 요건을 맞추려고 붙인 것이 아니라 **실제 필요에서 나왔습니다.**
사내 보안 데이터를 다루는 앱은 데이터를 외부 API로 내보낼 수 없습니다.
그래서 AI 계층을 처음부터 특정 제공자에 묶지 않고, 자체 서버에서 구동하는
오픈웨이트 모델로 바꿔 끼울 수 있게 설계했습니다.

AI 프록시는 OpenAI 호환 규격으로 요청하며 `/responses` 실패 시 `/chat/completions` 로
폴백합니다. 이는 Ollama·llama.cpp·vLLM·LM Studio가 공통으로 노출하는 규격이므로,
설정에서 `ai_openai_base_url` 만 로컬 런타임 주소로 바꾸면 상용 API 없이 같은 기능이
작동합니다. 실행 방법은 저장소의 **[doc/LOCAL_MODEL.md](../LOCAL_MODEL.md)** 에 문서화했습니다.

개발 중 OpenAI 호환 규격을 구현한 로컬 서버로 이 경로가 실제 동작하는 것을 확인했습니다.

```
설정 전환 — 상용 API → 로컬 런타임
응답 200 / content: 판정: 일치 — 로컬 모델이 응답했습니다.
로컬 런타임이 받은 요청:
  POST /v1/responses          ← 먼저 시도, 로컬 런타임엔 없으므로 404
  POST /v1/chat/completions   ← 폴백, 정상 응답
```

## 이 프로젝트가 연동할 수 있는 AI 제공자

심사에서 소스를 볼 때 참고가 되도록 정리합니다. 모두 **선택 사항**입니다.

| 경로 | 성격 | 비고 |
|---|---|---|
| OpenAI 호환 엔드포인트 | 상용 API **또는 자체 구동 오픈웨이트 모델** | `base_url` 교체로 전환. 온프레미스 기준 모델 Qwen2.5 |
| fal.run 경유 | 상용 API | 「나의 LLM」에서 Claude·Grok·Perplexity 계열 선택 |
| Tencent Cloud AIGC | 상용 API | 「나의 LLM」의 모델 선택 경로 |

사용자는 「나의 LLM」 앱에서 **쓰고 싶은 모델을 직접 고릅니다.** 출품작이 특정 모델을
지정하지 않으며, 키를 넣지 않으면 AI 기능만 비활성화되고 나머지는 그대로 동작합니다.
사내 보안 데이터를 다루는 앱에서는 온프레미스 경로를 사용합니다.

**모델 가중치는 저장소에 포함되어 있지 않습니다.**
