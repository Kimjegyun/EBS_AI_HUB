## ⚠️ 제출 전 반드시 해야 할 것

### 문제: 지금 상태로는 1번 체크가 사실과 다릅니다

확인한 현재 상태입니다.

| 항목 | 상태 |
|---|---|
| 로컬 모델 런타임 (ollama / llama.cpp / vLLM) | **미설치** |
| 허브 AI 설정 | `https://api.openai.com/v1` · `gpt-5.6-luna` — **상용 API** |
| 오픈웨이트 모델 실제 구동 | **없음** |

유형 1은 *"기존 **공개 모델**을 프로젝트에 연동·구동한 경우"* 입니다.
GPT는 가중치가 공개된 모델이 아니라 상용 API이므로, 지금 그대로면 유형 1에 해당하지 않고
오히려 부록2 Ⅱ장 **관문 2의 "제한"** 에 걸립니다 —
*"외부 상용 API를 빼면 핵심 기능이 전혀 작동하지 않는 서비스"*.

### 해결: 오픈웨이트 모델을 실제로 한 번 구동하세요

코드는 이미 준비돼 있습니다. AI 프록시가 `/responses` 실패 시 `/chat/completions` 로
폴백하는데, 이것이 Ollama·llama.cpp·vLLM이 공통으로 노출하는 규격입니다.
개발 중 OpenAI 호환 로컬 서버로 이 경로가 실제 동작하는 것까지 확인했습니다.

**남은 것은 진짜 모델을 한 번 올리는 것뿐입니다.**

```bash
# 1. https://ollama.com 에서 설치

# 2. 모델 내려받기 (약 4.7GB)
ollama pull qwen2.5:7b

# 3. 실행 확인
ollama ps
```

그다음 허브 관리자 화면 → **설정 → 환경 설정**에서 세 값을 바꿉니다.

| 설정 키 | 값 |
|---|---|
| `ai_openai_base_url` | `http://localhost:11434/v1` |
| `ai_openai_model` | `qwen2.5:7b` |
| `ai_openai_api_key` | 아무 문자열 (Ollama는 키를 검사하지 않습니다) |

마지막으로 재물조사 조사 화면에서 **AI 교차검증**을 한 번 실행해 로컬 모델이 응답하는지 확인하세요.

> 이 과정을 마치면
> - 1번 유형 1 체크가 **사실**이 됩니다
> - 2번 기반 모델에 `Qwen2.5-7B-Instruct (Alibaba Cloud) / Apache-2.0` 을 적을 수 있습니다
> - 관문 2의 *"오픈웨이트 모델로도 같은 기능이 작동한다"* 를 충족합니다
> - 시연 영상 【2:32–2:44】 구간을 실제 화면으로 찍을 수 있습니다
>
> **끝나면 알려주세요. 실제로 로컬 모델로 응답이 오는지 제가 확인해 드리겠습니다.**

### 만약 시간이 없어 로컬 구동을 못 한다면

그때는 유형 1 체크를 **빼고**, 붙임2를 다음과 같이 바꿔 제출하는 편이 안전합니다.
없는 것을 있다고 적는 쪽이 훨씬 위험합니다.

```
1. AI 모델 활용 유형
   □ 유형 1  □ 유형 2  □ 유형 3   ← 모두 미체크

   출품작에 AI 모델 가중치를 탑재하거나 배포하지 않습니다.
   AI 보조 기능은 선택 사항이며, 사용자가 지정한 OpenAI 호환 엔드포인트로 요청합니다.
   자산 실사를 비롯한 핵심 기능은 AI 없이 완전히 동작합니다.

2. 기반(베이스) 모델 정보
   해당 없음 (모델 가중치를 포함·배포하지 않음)

3. 데이터셋 정보 및 가중치 배포 명세
   해당 없음

4. (위와 동일하게 작성)
```

이 경우 **결과보고서 본문의 개발환경 항목에** "AI 보조 기능은 선택 사항이며 핵심 기능은
AI 없이 동작한다"는 점이 분명히 드러나야 합니다. 이미 그렇게 작성해 두었습니다.

판단이 애매하면 운영사무국(**contest@oss.kr**)에 문의하세요.
부록2가 *"제출 이후에 확인되면 되돌리기 어렵습니다"* 라고 명시합니다.

## 참고 — 이 프로젝트가 연동하는 AI 제공자

심사에서 소스를 볼 때 참고가 되도록 정리합니다. 모두 **선택 사항**이며,
사용자가 자신의 키를 넣지 않으면 동작하지 않고, 넣지 않아도 핵심 기능은 완전히 동작합니다.

| 경로 | 성격 | 비고 |
|---|---|---|
| OpenAI 호환 엔드포인트 | 상용 API **또는 자체 구동 오픈웨이트 모델** | `base_url` 교체로 전환. `/chat/completions` 폴백 있음 |
| Tencent Cloud AIGC | 상용 API | 선택 앱(나의 LLM)에서 모델 선택용 |
| fal.run | 상용 API | 선택 기능 |

**모델 가중치는 저장소에 포함되어 있지 않습니다.**
