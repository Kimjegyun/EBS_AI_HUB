## 방침 — 왜 유형을 체크하지 않는가

이 출품작은 **AI 모델 가중치를 포함하거나 배포하지 않습니다.**
AI 보조 기능은 선택 사항이고, 사용자가 자신의 키나 엔드포인트를 지정해야 동작합니다.
자산 실사를 비롯한 **핵심 기능은 AI 없이 완전히 동작합니다.**

부록2의 유형 1~3은 모두 **"공개된(오픈웨이트) 모델"** 을 전제로 합니다.
우리는 오픈웨이트 모델을 내려받아 구동하는 경로를 제공하지만, 특정 모델을 출품작에
탑재하거나 지정해 배포하지 않습니다. 따라서 **어느 유형에도 체크하지 않고**
그 사실을 명시하는 것이 정확합니다.

> **붙임2 자체는 제출하는 것을 권합니다.** 서식에 *"해당 사항 없을 경우 붙임2 영역 삭제"*
> 안내가 있지만, 이 출품작은 실행 중에 AI 엔드포인트를 호출하는 코드를 포함합니다.
> 2차 평가에서 소스코드를 분석하므로 명세서가 없으면 숨긴 것처럼 보입니다.
> 유형만 비우고 상황을 적어 내는 편이 훨씬 안전합니다.

## 관문 2에 걸리지 않는 근거 (심사 문의 대비)

부록2 Ⅱ장 관문 2가 제한하는 것은 *"외부 API 호출을 통해서만 작동하는 상용 API 전용
모델을 서비스 형태로 단순 연결한"* 출품작, 즉 **API를 빼면 아무것도 동작하지 않는 경우**입니다.
이 출품작은 두 가지 이유로 해당하지 않으며, 둘 다 저장소에서 확인 가능합니다.

**첫째, 핵심 기능이 AI를 쓰지 않습니다.**

| 기능 | AI 필요 |
|---|---|
| QR 스캔 → 자산 조회 (하이픈 무시 매칭) | ❌ |
| 운영관리부 양식 + ERP 엑셀 병합 | ❌ |
| 검수 기록 · 오프라인 동기화 | ❌ |
| 검수 4열 반영 ERP 엑셀 생성 | ❌ |
| 설치부서 대조(노랑/주황) 엑셀 생성 | ❌ |
| 본부 → 부서 → 확인자 커버리지 통계 | ❌ |
| 앱 마켓플레이스 · 원격 앱 배포 · 앱 이식 | ❌ |
| 장부·현물 대조 AI 교차검증 *(선택)* | ⭕ |

AI 키를 한 줄도 넣지 않아도 전 과정이 동작합니다.

**둘째, 오픈웨이트 모델 독립 구동 경로를 제공합니다.**

AI 프록시는 OpenAI 호환 규격으로 요청하며 `/responses` 실패 시 `/chat/completions` 로
폴백합니다. 이는 Ollama·llama.cpp·vLLM·LM Studio가 공통으로 노출하는 규격이므로,
설정에서 `ai_openai_base_url` 만 로컬 런타임 주소로 바꾸면 상용 API 없이 같은 기능이
작동합니다. 실행 방법은 저장소의 **[doc/LOCAL_MODEL.md](../LOCAL_MODEL.md)** 에 문서화했습니다.

개발 중 OpenAI 호환 규격을 구현한 로컬 서버로 이 경로가 실제 동작하는 것을 확인했습니다.

```
설정 전환 — 상용 API → 로컬 런타임
응답 200 / content: 판정: 일치 — 로컬 모델이 응답했습니다.
로컬 런타임이 받은 요청:
  POST /v1/responses          ← 먼저 시도, 로컬 런타임엔 없으므로 404
  POST /v1/chat/completions   ← 폴백, 정상 응답
```

> 여유가 되면 **Ollama + Qwen2.5(Apache-2.0)로 한 번 실제 구동**해 보시길 권합니다.
> 필수는 아니지만, 시연 영상에 그 장면을 넣으면 관문 2 논쟁의 여지가 사라집니다.
> 방법: `ollama pull qwen2.5:7b` → 설정에서 `ai_openai_base_url` 을
> `http://localhost:11434/v1`, `ai_openai_model` 을 `qwen2.5:7b` 로 변경.

## 이 프로젝트가 연동할 수 있는 AI 제공자

심사에서 소스를 볼 때 참고가 되도록 정리합니다. 모두 **선택 사항**입니다.

| 경로 | 성격 | 비고 |
|---|---|---|
| OpenAI 호환 엔드포인트 | 상용 API **또는 사용자가 구동하는 오픈웨이트 모델** | `base_url` 교체로 전환 |
| Tencent Cloud AIGC | 상용 API | 선택 앱(나의 LLM)의 모델 선택용 |
| fal.run | 상용 API | 선택 기능 |

**모델 가중치는 저장소에 포함되어 있지 않습니다.**
