# EBS AI Hub 앱 스타터

이 폴더를 복사해 독립 앱 프로젝트로 사용하세요. Node.js 18 이상이 필요하며 추가 npm 의존성은 없습니다.

## 만들기와 미리보기

1. `aihub-app.json`의 `id`, `name`, `version`, `author`, `description`을 수정합니다. `id`는 고유해야 합니다.
2. `app.js`에서 앱을 구현합니다. 기본 내보내기 함수가 `{ Body }`를 반환해야 하며, React는 함수 인자로 받습니다.
3. 로컬 패키지를 생성합니다.

```sh
npm run package
```

`dist/<id>@<version>.aihubapp.json`이 생성됩니다. 파일을 텍스트 편집기로 열어 코드·메타데이터를 확인하세요. 이 스타터의 패키징은 코드를 번들하거나 JSX를 변환하지 않습니다. `app.js`를 자체 완결된 ESM으로 작성하고, `React.createElement`를 사용하세요.

4. EBS AI Hub에 로그인하고 앱 제출 화면에서 **로컬 미리보기**를 눌러 `.aihubapp.json`을 선택합니다. 대시보드의 앱 추가 화면에서 미리보기 앱을 열어 동작을 확인합니다. 미리보기는 현재 브라우저에서만 실행되며 서버에 업로드되지 않습니다.
5. 확인이 끝나면 **앱 제출**에서 같은 패키지 파일을 선택합니다. 패키지의 정보를 확인하고 필요한 권한만 선택한 뒤 심사자 메모를 작성해 **심사 요청**을 누릅니다. 제출된 코드는 관리자가 검토하며 승인 후 마켓플레이스에 공개됩니다.

Windows PowerShell에서도 동일하게 실행할 수 있습니다.

```powershell
npm run package
```

## 처음부터 제출까지

1. 이 `starter/` 폴더를 복사하고 Node.js 18 이상을 준비합니다. 별도 `npm install`은 필요하지 않습니다.
2. `aihub-app.json`의 `id`, `name`, `version`, `description`, `author`를 수정합니다. `id`는 고유한 영문 소문자 ID로 시작하고, 버전을 바꿔 제출할 때마다 올립니다.
3. `app.js`에서 `createApp({ React })`와 `Body`를 수정합니다. `React.createElement`로 화면을 만들며 React나 다른 모듈을 import하지 않습니다.
4. 이 폴더에서 패키지를 만듭니다.

   ```sh
   npm run package
   ```

   `dist/<id>@<version>.aihubapp.json`이 생성됩니다. 이 명령은 패키지를 만들지만 앱을 실행하거나 빌드하지 않습니다.
5. AI Hub에 로그인하고 **마켓플레이스 → 내 앱 제출 → 로컬 미리보기**에서 패키지를 선택해 대시보드에서 동작을 확인합니다. 로컬 미리보기는 서버로 제출되지 않습니다.
6. **앱 제출**에서 같은 파일을 선택하고 앱 정보·권한·심사 메모를 검토한 뒤 심사 요청을 보냅니다. 제출 상태는 심사 대기이며 관리자 승인 후에만 마켓플레이스에 공개됩니다.

## 지원 범위

- 앱은 Hub가 제공하는 React와 `Body` 화면을 사용하는 브라우저 앱입니다. 앱의 기본 타일은 4 × 3입니다.
- `network`는 HTTPS 네트워크 권한, `storage`는 앱별 사용자 저장 공간을 요청합니다. 나머지 `hub-api`, `ai`, `clipboard` 권한도 선언 자체로 Hub 로그인 토큰, API, AI 키 또는 클립보드 기능이 자동 제공되지는 않습니다.
- 현재 외부 앱에 공개된 Hub 업무 API는 없습니다. Hub API·AI·OAuth·Drive 연동이 필요하면 운영자와 서버 연동 계약을 먼저 협의하세요. 브라우저 코드에 비밀 키를 넣지 마세요.
- ZIP 다운로드 주소는 개발킷을 내려받는 주소입니다. 실제 제출은 로그인한 Hub의 앱 제출 화면에서 진행하며, 운영 토큰이나 자동 제출 CLI를 사용하지 않습니다.

## 제출이 거절되거나 보이지 않을 때

- `import`·동적 import·JSX·여러 파일 의존성을 제거하고 `app.js` 한 파일에 작성합니다.
- 패키지 용량이 2MB 이내인지 확인합니다.
- 앱 ID가 다른 앱 소유자의 ID와 겹치지 않는지 확인합니다.
- 같은 앱 ID로 다시 제출할 때 버전을 올립니다.
- 제출 직후 앱이 마켓플레이스에서 보이지 않는 것은 심사 대기 상태라면 정상입니다. 제출 현황의 심사 메모를 확인하세요.

## 구현 규칙

- `app.js`에 `export default function createApp({ React }) { return { Body } }` 형식으로 작성합니다.
- React를 import하지 않습니다. npm 패키지나 외부 import는 이 패키저에서 해결되지 않습니다.
- 앱 자체를 직접 테스트하려면 `npm run package` 후 Hub의 로컬 미리보기를 사용합니다.
- 네트워크, 저장소 등은 킷의 `APP_DEVELOPER_GUIDE.html`에서 지원 범위를 확인하세요. 권한 선언만으로 Hub API·AI 서비스가 연결되지는 않습니다.
- `dist/`는 생성 결과이며 제출 후 다시 만들 수 있습니다. 비밀값이나 사용자 데이터를 소스에 넣지 마세요.

## 제출 메모 권장 내용

앱의 목적, 테스트한 시나리오, 외부 통신 대상과 전송 데이터, 각 요청 권한의 이유를 설명하세요. 심사 결과는 Hub의 **내 앱 제출** 현황에서 확인합니다. 반려된 경우 심사 의견을 반영하고 버전을 올려 다시 제출하세요.
