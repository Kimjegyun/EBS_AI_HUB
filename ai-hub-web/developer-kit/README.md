# EBS AI Hub 외부 앱 개발자 킷

이 폴더는 AI Hub에 제출할 앱의 문서와 실행 가능한 스타터 프로젝트를 한곳에서 관리합니다.

- [`APP_DEVELOPER_GUIDE.md`](APP_DEVELOPER_GUIDE.md): 지원 계약, 구현 제약, 미리보기·제출·심사 순서. ZIP에는 읽기 쉬운 `APP_DEVELOPER_GUIDE.html`도 함께 넣습니다.
- [`starter/`](starter/): Node.js 기본 모듈만 사용하는 최소 앱 프로젝트

## 릴리스 패키지

배포용 ZIP은 저장소의 `public/downloads/`에 두고, 공개 자료실 페이지는 `public/developer-kit/`에서 관리합니다. ZIP에는 가이드와 `starter/`를 포함하고 빌드 결과물(`starter/dist/`)은 넣지 않습니다. 새 릴리스에서는 `developer-kit/README.md`와 공개 자료실 페이지의 버전을 함께 갱신하고 ZIP을 다시 만드세요.
