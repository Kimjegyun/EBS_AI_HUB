# AI HUB 가입 승인 전용 Android 앱

가입 승인 화면은 무료로 설치 가능한 PWA로 제공한다. Android Chrome에서 `https://ebs-aihub.com/admin/approvals/`를 열면 전용 앱 진입 경로로 이동한다. 이 화면에서 Chrome 메뉴의 앱 설치 또는 홈 화면에 추가를 선택하면 홈 화면에 `AI HUB 승인` 앱이 생긴다. 전용 매니페스트 ID, 시작 주소, 아이콘을 사용해 재물조사 앱과 별도 설치 앱으로 구분한다.

앱은 독립된 설치 이름과 아이콘, 전체 화면 레이아웃을 사용하며 실행 시 승인 대기 목록을 바로 연다. 일반 관리자 화면의 로그인, 승인 권한, 기존 이메일 알림 및 웹 푸시 백엔드를 그대로 쓴다. 새 가입 알림을 누르면 이 전용 화면으로 이동한다. 주기적 조회는 하지 않으며, 서버에서 가입 알림 푸시가 발행될 때마다 기기 알림을 띄우고 앱이 열려 있으면 신청 목록을 즉시 갱신한다.

각 관리자는 앱에서 로그인한 뒤 알림 켜기를 누르고 Chrome 알림 권한을 허용해야 해당 기기로 푸시를 받는다. 관리자가 승인한 뒤 모든 승인 관리자에게 처리 결과 메일이 전송되고, 가입자에게는 환영 메일이 전송된다. 다른 관리자가 먼저 승인한 요청은 이미 승인됨으로 표시한다.

이 방식은 APK나 Google Play 개발자 등록 없이 사용할 수 있다. 웹 앱 업데이트는 포털 배포 후 다음 실행 때 반영된다.
