# 유틸리티 자료실

- 공개 목록: `/util`
- 상세 문서: `/util/<주소 ID>`
- 이전 페이지 버전: `/util/<주소 ID>?version=1.0.0`
- 배포된 관리자 포털의 작성 화면: `/admin/util`

관리자는 **새 유틸리티 포스팅**에서 제목, 소개, 분류, 특징, 사용법, 변경 내용, 선택적인 실행·다운로드 링크를 입력하고 공개 발행합니다. **새 개정판 작성**은 최신 문서를 복사하며 새 버전 번호와 변경 내용을 요구합니다. 기존 발행 내용은 덮어쓰지 않고 그대로 보존합니다. 페이지 버전은 문서의 버전이며 실행 파일의 버전이나 Git 커밋을 자동으로 추적하지 않습니다.

본문은 일반 텍스트와 줄바꿈으로 표시합니다. 공개된 게시물만 다루며 초안 자동 저장이나 파일 업로드는 포함하지 않습니다. 실행·다운로드 링크로 별도 프로그램에 연결할 수 있습니다.

데이터는 기존 서버 SQLite DB의 `utility_revisions` 테이블에 저장합니다. 서버 시작 시 기존 데이터에 영향을 주지 않고 테이블을 생성합니다. DB 백업에 문서 이력도 포함됩니다. 공개 읽기 API는 `GET /api/utilities`, `GET /api/utilities/:slug`이며, 발행 API `POST /api/utilities`는 기존 관리자 인증을 요구합니다.

운영 반영에는 프런트(관리자·사용자 포털), 서버, `scripts/serve-public-portals.mjs` 게이트웨이를 함께 갱신해야 합니다. 게이트웨이는 `/util`에서 사용자 포털 HTML을 제공하며, 공개 문서 GET 외 쓰기 요청은 기존 인증 경계를 유지합니다.

검증: `node server/node_modules/tsx/dist/cli.mjs --test scripts/utilities.test.ts`
