# 소스 폴더 → AI Hub 마켓플레이스

이 기능은 AI Hub 저장소 소유이며 ACAP 원격/로컬 소스를 변경하지 않습니다.

## 관리자 버튼

관리자 **앱 등록 → 프로그램 가져오기**에서 다음 작업을 실행합니다.

- **폴더 검사**: 서버의 `import_program` 하위 폴더별 매니페스트·진입 파일·중복 id 검사
- **패키지 생성 실행**: 소스 빌드와 패키지 생성
- **빌드 후 자동 제출**: 빌드 후 현재 관리자 로그인으로 기존 심사 API에 제출

브라우저에서 토큰이나 서버 주소를 따로 입력할 필요가 없습니다. 제출은 1회 실행이며 지속 감시는 CLI `--watch`를 사용합니다. 승인 절차는 기존 심사 대기열을 사용합니다. 폴더는 **서버가 실행되는 PC** 기준입니다. 원격 브라우저의 개인 PC 폴더를 읽는 기능은 아닙니다.

작업은 서버에서 한 번에 하나만 실행하고 최대 5분으로 제한합니다. 화면은 진행 상태와 폴더별 결과를 자동 조회합니다. 페이지를 이동해도 작업이 계속되지만 서버 재시작 후 최근 작업 화면 상태는 초기화됩니다. 제출 중복 방지 기록은 기존 `state.json`을 사용합니다.

배포 시 프런트·서버를 함께 갱신하고 서버 루트에 `scripts/import-programs.mjs`, `import_program`, 루트 빌드 의존성(Vite 포함)을 준비해야 합니다. 정적 프런트만 배포하면 서버 폴더 작업을 실행할 수 없습니다.

## 사용

1. `import_program/<프로그램명>/`에 소스를 복사합니다. `_example`을 복사해 시작할 수 있습니다. 예제가 필요 없으면 `_example` 폴더를 밖으로 옮기세요.
2. `aihub-app.json`에 고유 `id`, `name`, `version`, `category`, `entry`, `permissions`를 선언합니다. 선택 항목은 `description`, `icon`, `author`, `license`, `sourceUrl`입니다.
3. `npm run import:programs`로 모든 하위 폴더를 빌드합니다.
4. `import_program/.packages/*.aihubapp.json`을 마켓플레이스의 기존 앱 제출 화면에서 미리보기·제출합니다.
5. 관리자가 기존 심사 대기열에서 코드를 확인하고 승인하면 마켓플레이스에서 공유·설치할 수 있습니다.

`npm run import:programs -- --watch`는 5초마다 순차 재빌드합니다. 실패한 폴더도 다음 회차에 재시도하며 다른 폴더 처리는 계속됩니다. `report.json`에 폴더별 결과가 기록됩니다.

## 자동 심사 제출

PowerShell에서 현재 사용자 세션의 서버 API 토큰을 환경 변수로 제공하고 실행합니다. 토큰은 소스·매니페스트·문서에 저장하지 않습니다.

```powershell
$env:AIHUB_IMPORT_API_URL = 'https://ebs-aihub.com'
# AIHUB_IMPORT_TOKEN은 기존 로그인에서 발급된 서버 API 토큰으로 설정
npm run import:programs -- --submit --watch
```

자동 제출도 `/api/apps/remote/submit`을 사용하므로 관리자 토큰을 사용해도 심사를 건너뛰지 않습니다. API 주소는 허브 서버의 origin 또는 API가 배치된 기본 경로입니다. 동일 서버·id·버전·패키지를 성공적으로 제출한 기록은 `state.json`에 남아 다음 제출을 생략합니다. 응답 유실이나 상태 파일 삭제 후에는 내 제출 목록을 확인하세요. 서버가 중복 버전을 거부하면 새 버전을 사용하세요. 새 릴리스는 매니페스트의 `version`을 올려 제출합니다. 배포 중인 이전 버전은 기존 승인 정책을 따릅니다.

## 현재 지원 범위와 어댑터 계약

현재는 브라우저에서 실행할 수 있는 JS/TS 앱 팩토리를 단일 ESM으로 번들합니다. `entry`는 `export default ({ React }) => ({ Body, defaultSize })` 형식이며 호스트 React를 사용합니다. 로컬 모듈 import는 번들에 합쳐집니다. React를 별도로 import하지 마세요. JSX 변환 설정에 의존하지 않는 `React.createElement` 예제를 제공합니다. 별도의 npm install/build 스크립트는 실행하지 않습니다. 필요한 라이브러리는 해당 프로그램 내부에서 준비해야 합니다.

CSS 파일·외부 자산·미해결 import가 남거나 2MB를 초과하면 실패합니다. 스타일은 컴포넌트 안에서 지정하고 자산은 인라인으로 준비하세요. 소스 파일 접근은 프로그램 폴더 내부로 제한하고 `.env`·키 파일의 직접 번들 포함을 거부합니다. 소스에 직접 적힌 비밀값까지 탐지하지는 않으므로 패키지 코드를 검토해야 합니다.

독립 React 웹사이트는 루트 마운트 대신 Body 컴포넌트를 반환하도록 어댑터를 작성해야 합니다. Python·데스크톱·백엔드 프로그램은 이 빌드로 변환되지 않습니다. 별도 서비스 배포와 인증된 서버 어댑터가 필요합니다. 공통 로그인·OAuth·Google Drive·API 키 관리는 AI Hub 서버 계약을 사용하고 비밀값을 패키지에 포함하지 않습니다.

패키징 시 프로그램 코드를 직접 실행하지 않으며 프로그램 내부 Vite·PostCSS 설정도 실행하지 않습니다. 미리보기와 승인된 앱은 `allow-same-origin` 없는 sandbox iframe에서 실행합니다. 허브의 로그인 토큰·문서·저장소는 전달하지 않습니다. `network` 선언이 있는 앱만 HTTPS 네트워크에 접근할 수 있으며 `storage` 선언은 계정·앱별 64KB 저장 공간에 한정됩니다. 허브 API·AI 호출에 호스트 인증을 자동 제공하지 않으므로 해당 기능은 별도 서버 연동 계약이 필요합니다. 관리자 코드 심사는 계속 필요합니다. iframe 격리는 CPU·운영체제 수준의 자원 격리를 보장하지 않습니다. 서버 프로그램 배포는 포함하지 않습니다.
