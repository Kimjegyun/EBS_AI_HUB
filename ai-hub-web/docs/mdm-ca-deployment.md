# EBS AI HUB MDM 인증서 배포

재물조사 앱의 로컬 HTTPS 접속에 사용하는 루트 CA를 기관 관리 단말에 배포합니다.

## Android Enterprise

1. Admin의 `재물조사 설정 → 기관 단말 MDM 인증서 배포`에서 `Android DER`를 다운로드합니다.
2. MDM의 신뢰할 수 있는 인증서(Trusted certificate) 정책에 `.cer` 파일을 등록합니다.
3. 용도는 VPN/Wi-Fi 클라이언트 인증서가 아닌 `Root CA / Trusted credential`로 선택합니다.
4. Fully Managed 또는 COPE 기기 그룹에 필수 정책으로 할당합니다.
5. 단말 동기화 후 인증서 지문이 manifest의 SHA-256 값과 같은지 확인합니다.

## iOS / iPadOS

1. `iOS 프로파일`을 다운로드합니다.
2. MDM의 사용자 지정 구성 프로파일에 `.mobileconfig`를 업로드합니다.
3. 감독 대상 기기 그룹에 필수 설치로 할당합니다.
4. 배포 완료 후 인증서 페이로드가 설치되었는지 MDM 상태에서 확인합니다.

## 운영 주의사항

- 이 CA의 개인키가 있는 서버 디렉터리는 관리자만 접근할 수 있어야 합니다.
- CA가 변경되면 새 인증서를 먼저 배포한 후 기존 인증서를 제거합니다.
- MDM에서 배포되지 않은 개인 단말에는 사용자 직접 설치 제한이 계속 적용될 수 있습니다.
- 실제 MDM 배포 실행에는 해당 MDM 관리자 권한과 대상 기기 그룹 선택이 필요합니다.
