# 작업 자원 설정

AI Hub 공통 플랫폼 기능이다. ACAP 원격·로컬 저장소는 변경하지 않는다.

관리자 `/admin/settings` → **작업 자원 설정**에서 작업별 처리 위치와 서버 동시 작업 수를 저장한다.

| 작업 | 중앙 서버 | 사용자 PC |
|---|---|---|
| 음성 전처리 | 원본 업로드 후 기존 FFmpeg 변환·분할 | Web Audio로 16kHz 모노 PCM WAV, 120초 단위 변환·분할 후 순차 업로드 |
| 사용자 ERP 엑셀 읽기 | 제한된 서버 Worker에서 읽고 결과 반환 | 브라우저 Worker에서 읽기, 원본 업로드 없음 |

적용 범위는 음성요약의 전처리와 재물조사의 사용자 ERP 가져오기다. 기존 문서 내보내기·개인 프로젝트 저장 등 브라우저 작업은 유지한다. 공용 원본 업로드 검증·DB 반영·최종 병합은 중앙 서버가 담당한다. 외부 AI 추론은 계속 서버가 보관하는 API 키로 호출한다. 로컬 AI 모델/GPU 추론이나 크레딧 산식 변경은 포함하지 않는다.

## 동작 및 한계

모바일 고부하 작업의 서버 자동 처리는 기본적으로 켜진다. 관리자 화면의 **모바일 고부하 작업 서버 처리**에서 끌 수 있다. PC의 사용자 자원 기본값은 유지한다.

- 음성: 파일 5MB 초과, 길이 3분 초과 또는 메타데이터로 길이를 3초 내 확인하지 못하면 서버 처리한다.
- 엑셀: 파일 2MB 초과 또는 ZIP 디렉터리로 계산한 압축 해제 예상 크기 16MB 초과면 서버 처리한다.
- CPU 논리 코어가 2개 이하로 보고되는 모바일은 작은 파일도 서버 처리한다.
- Android·iPhone·iPad 및 데스크톱 사용자 에이전트를 쓰는 터치 iPad를 감지한다. 이 기준은 실제 기기 성능 측정값이 아닌 보수적인 운영 기준이다.
- 자동 전환 시 브라우저 음성 디코딩·엑셀 압축 해제를 생략하고 `X-AIHub-Execution: mobile-central` 힌트와 함께 원본을 보낸다. 서버는 관리자 정책이 켜진 경우만 예외를 허용한다. 기기 힌트는 보안 경계가 아니며 인증·파일 크기·동시 작업 제한을 유지한다.

- 초기값: 음성·ERP 모두 사용자 PC 처리, 서버 동시 작업 2건. 모바일도 같은 초기값을 사용한다. 저장된 관리자 설정이 있으면 해당 설정을 우선하며, 관리자가 저장하면 다음 작업부터 적용된다.
- `environment_config.data.resource_policy`에 영구 저장한다. 별도 Supabase 설정 사본을 사용하지 않는다. 일반 환경설정 저장은 이 필드를 변경하지 않는다.
- `GET /api/resources`: 승인된 사용자에게 처리 정책만 제공한다. 비밀값을 반환하지 않는다.
- `PUT /api/resources`, `GET /api/resources/status`: 관리자 전용. 모드와 동시 작업 수(1~4)를 서버에서 검증한다.
- `POST /api/resources/workbook`: 중앙 ERP 읽기 전용. 사용자 PC 모드에서는 관리자가 허용한 모바일 자동 전환 요청만 예외로 처리하고 나머지는 409로 거부한다. 파일은 DB에 저장하지 않는다.
- 음성 및 중앙 ERP 읽기는 업로드 버퍼 생성 전 공통 동시 작업 제한을 적용한다. 한도 초과 시 `429`, `Retry-After: 5`로 재실행을 안내한다. 대기열은 제공하지 않는다. 기존 엑셀 파서의 동시 2건 상한도 유지된다.
- 제한은 서버 프로세스별이다. 다중 프로세스·다중 서버 운영 시 분산 제한 장치가 별도로 필요하다. 다른 제작 앱·기존 원본 처리에 대한 전역 자원 제한은 아니다.
- 음성 사용자 PC 모드는 파일당 최대 50MB·1시간, 구간당 최대 4MB다. 브라우저는 원본을 디코딩하므로 긴 음성은 사용자 메모리를 사용한다. 브라우저에서 지원하지 않는 코덱은 중앙 처리로 전환하거나 파일 형식을 바꾸어야 한다.
- 사용자 PC에서 전처리한 음성은 서버가 실제 WAV 헤더·길이·16kHz 모노 PCM 형식을 검증하며 FFmpeg를 실행하지 않는다. 모바일 자동 전환 요청은 중앙 처리 경로를 이용한다.
- 설정 조회나 로컬 처리 실패 시 서버로 자동 우회하지 않는다. 모드 변경 중 요청은 기존 업로드 정책에 따라 거부될 수 있으므로 새로 실행한다.
- 사용자 모드는 탭을 닫거나 PC가 절전 상태가 되면 중단될 수 있다. API 비용은 계속 발생한다. AI Hub를 로컬 AI 추론 서버로 변경하는 기능은 아니다.
- 서버 FFmpeg 변환은 120초 제한을 적용한다.
- WAV는 브라우저 코덱 차이를 줄이기 위한 전송 형식이다. 압축된 MP3 등보다 전송량이 커질 수 있으며, 사용자 모드를 업로드 용량 절감 기능으로 보장하지 않는다.

## 검증

```powershell
npm.cmd run test:resources
node scripts/verify-resource-execution-browser.mjs
```

API 테스트는 메모리 DB와 모의 AI 제공자를 사용한다. 관리자 권한, 설정 보존, 모드 강제, 업로드 크기·형식, 중앙 엑셀 읽기, 동시 요청 거부·처리 슬롯 반환을 검증한다.

브라우저 검증은 Chrome/Edge를 사용한다. 실제 Web Audio 변환·구간 경계, 엑셀 Worker·크기 제한, 사용자 모드 업로드 없음, 중앙 모드 업로드, 설정 실패 시 우회 차단과 공개 빌드 관리자 UI를 확인한다. 운영 API는 모의 응답으로 대체하며 실계정·실제 AI 비용을 사용하지 않는다. `PORTAL_TEST_ORIGIN`으로 공개 빌드 검사 주소를 지정할 수 있다.

이는 기능·회귀 검증이며 동시 사용자 수에 대한 부하 시험이나 모든 기기의 코덱 호환성을 보장하는 시험은 아니다.
