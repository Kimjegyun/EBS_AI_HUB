EBS AI Hub 앱 개발자 자료실

마켓플레이스에 호환되는 브라우저 앱을 만드는 가이드와 시작 프로젝트입니다. ZIP을 내려받아 압축을 풀고 starter/README.md부터 따라 하세요.

개발자 킷 다운로드 (v1.0.0) 온라인 가이드 읽기

빠른 시작

  1. ZIP을 풀고 starter/에서 앱 매니페스트와 코드를 수정합니다.
  2. Node.js 18 이상에서 npm run package를 실행합니다.
  3. Hub의 앱 제출 패널에서 생성된 .aihubapp.json을 로컬 미리보기로 확인합니다.
  4. 같은 파일을 앱 제출에 올려 관리자 심사를 요청합니다. 승인 후 마켓플레이스에 공개됩니다.

현재 킷은 React 기반 단일 파일 브라우저 앱용입니다. 서버 앱과 Hub 인증 API 연동은 별도 계약이 필요합니다. 가이드에서 권한과 실행 제한을 확인하세요.
